# Loopr

A free macro recorder for Mac. Record your mouse and keyboard, then play it back, loop it, or speed it up.

## Download
Grab **Loopr.zip** from the Releases page, unzip it, and drag Loopr into Applications.

## First-time setup
1. Right-click Loopr → **Open** (macOS warns because the app isn't signed by Apple).
2. System Settings → Privacy & Security → turn on Loopr in **Accessibility** and **Input Monitoring**.
3. Quit Loopr and open it again.

## Controls
| Action | Key |
| --- | --- |
| Record / stop recording | F8 (fn + F8 on MacBooks) |
| Play / stop | F10 (fn + F10) |
| Emergency stop | Esc |

Loop and speed (0.5x–10x) are in the window. Macros can be saved and opened as `.loopr` files.

Works in any app or game. Check a game's rules before using macros in it.
